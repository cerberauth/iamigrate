`iamigrate import` has one subcommand per target provider.

- [iamigrate import auth0](./auth0/) — Chunk, submit, poll, and import a CMF file into an Auth0 tenant.
- [iamigrate import cognito](./cognito/) — Create AWS Cognito user pool users from a CMF file via the admin API.
- [iamigrate import firebase](./firebase/) — Create Firebase Authentication users from a CMF file via the Identity Toolkit API.
- [iamigrate import keycloak](./keycloak/) — Create Keycloak users from a CMF file via the Admin API.
- [iamigrate import kratos](./kratos/) — Create Ory Kratos identities from a CMF file via the Admin API.
