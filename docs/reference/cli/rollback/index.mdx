---

`iamigrate rollback` has one subcommand per target provider.

- [iamigrate rollback auth0](./auth0/) — Delete the users of a CMF file from an Auth0 tenant.
- [iamigrate rollback kratos](./kratos/) — Delete the users of a CMF file from an Ory Kratos instance.
