`iamigrate diff` has one subcommand per target provider.

- [iamigrate diff auth0](./auth0/) — Reconcile a CMF file against a live Auth0 tenant.
- [iamigrate diff cognito](./cognito/) — Reconcile a CMF file against a live AWS Cognito user pool.
- [iamigrate diff firebase](./firebase/) — Reconcile a CMF file against a live Firebase project.
- [iamigrate diff keycloak](./keycloak/) — Reconcile a CMF file against a live Keycloak realm.
- [iamigrate diff kratos](./kratos/) — Reconcile a CMF file against a live Ory Kratos instance.
